web-gather studio

free web research · no API keys · v?

Gathers pages from the web, extracts the evidence, then answers in one paragraph with sources.

AI not configured - add OLLAMA_API_KEY to .env (or run local Ollama) for an AI-written paragraph; for now you get a compiled one.

Or: search first, then crawl the best results.

Returns verifiable evidence: claim + exact quote + source + confidence.

Use from any website

CORS is open by default, so browser code from any origin can call the API.

// search
const r = await fetch('http://localhost:8001/v1/search?q=windows+13+leaks');
const data = await r.json();
data.results.forEach(x => console.log(x.title, x.url));

// crawl corpus (background job, poll status)
let job = await fetch('/v1/jobs', {method:'POST', headers:{'Content-Type':'application/json'},
  body: JSON.stringify({sources:['https://news.example.com/feed.xml'], options:{max_pages:20}})});
let id = (await job.json()).job_id;
while (true) {
  let s = await (await fetch(`/v1/jobs/${id}`)).json();
  console.log(s.state, s.status);
  if (s.state === 'done') break;
  await new Promise(r => setTimeout(r, 1500));
}

// research goal -> evidence
let jr = await (await fetch('/v1/research', {method:'POST', headers:{'Content-Type':'application/json'},
  body: JSON.stringify({goal:'Are ultra-processed foods linked to heart disease?'})})).json();
let rr = await (await fetch(`/v1/research/${jr.job_id}`)).json();
rr.findings.forEach(f => console.log(f.confidence, f.finding, f.source_url, f.quote));

// ask -> one AI paragraph (uses OLLAMA_API_KEY when set)
let ans = await (await fetch('/v1/ask', {method:'POST', headers:{'Content-Type':'application/json'},
  body: JSON.stringify({question:'Are ultra-processed foods linked to heart disease?'})})).json();
console.log(ans.paragraph);
ans.sources.forEach(s => console.log('-', s.title, s.url));
